# Exemplos para começar

Substitua os campos entre colchetes por informações reais.

## Diagnosticar o comercial

```text
ZE MARRETA, use o framework de sete etapas.
Vendo [produto] para [público], com ticket de [valor].
No último [período], tivemos [leads], [reuniões], [propostas] e [vendas].
Nossa equipe tem [estrutura]. O principal problema percebido é [problema].
Mostre o gargalo provável, os dados que faltam e uma ação prioritária.
Não trate dados incompletos como prova.
```

## Preparar uma reunião

```text
Crie um roteiro consultivo para [produto], ticket [valor], prospect [perfil].
Use SPIN e micropactos voluntários. Já sabemos: [contexto].
Entregue perguntas, transições, critérios para apresentar a oferta e próximo passo.
Marque como placeholder qualquer prova ou número que eu ainda precise fornecer.
```

## Responder a uma objeção

```text
O cliente disse: [frase exata].
Contexto: [produto, ticket, etapa, decisores e condições já discutidas].
Consulte o playbook de objeções. Diferencie hipóteses de fatos e escreva
uma resposta curta para [canal], seguida de uma pergunta de diagnóstico.
```

## Desenhar ofertas

```text
Use Money Models na etapa 7 para organizar as ofertas de [negócio].
Hoje vendemos [oferta], com preço [valor], custo de entrega [valor],
capacidade [limite] e recompra [histórico].
Proponha entrada, complemento, alternativa de escopo e continuidade.
Se faltarem dados de margem ou demanda, indique o que validar primeiro.
```

## Conferir se a configuração funciona

Peça um diagnóstico e confira se a IA identifica a etapa, explica a hipótese e cita arquivos que recebeu. Peça um script e veja se os dados ausentes ficam como placeholders. Se ela alegar acesso a documentos não enviados, corrija a configuração antes de usar as respostas com clientes.
